# Export pendente

Este diretório deve receber o export oficial:

```text
[CDXMS]_Bootstrap.ablock
```

O export deve ser criado no MacroDroid real a partir do `body.md`, porque a chamada ao `[CDXMS] Json Config Manager` usa `ActionBlockAction` e depende de IDs internos gerados pelo MacroDroid.

Não gerar esse `.ablock` manualmente antes de validar importação e execução.
