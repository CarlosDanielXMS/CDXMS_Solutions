# [CDXMS] Bootstrap v1.0.0

Coordenador local de inicialização do ecossistema CDXMS usando o JCM.

## Responsabilidade

Esta capability executa somente o domínio descrito em seu contrato. A saída pública única é `Resultado`.

## Operações

- `initialize_ecosystem`
- `verify_core`
- `repair_core`
- `ensure_runtime`
- `load_context`
- `get_status`

## Dependências

{"json_config_manager": ">=1.0.0"}

## Distribuição

O export MacroDroid está em `macrodroid/[CDXMS]_Bootstrap.ablock`. A importação continua manual até homologação específica de importação automática.
