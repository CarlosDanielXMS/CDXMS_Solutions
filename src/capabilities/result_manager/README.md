# [CDXMS] Registrar Resultado v1.0.0

Capability pura para construir, normalizar, validar e propagar Resultado.

## Responsabilidade

Esta capability executa somente o domínio descrito em seu contrato. A saída pública única é `Resultado`.

## Operações

- `build_result`
- `normalize_result`
- `validate_result`
- `propagate_result`
- `wrap_error`
- `register_result`

## Dependências

Nenhuma capability obrigatória além do core.

## Distribuição

O export MacroDroid está em `macrodroid/[CDXMS]_Registrar_Resultado.ablock`. A importação continua manual até homologação específica de importação automática.
