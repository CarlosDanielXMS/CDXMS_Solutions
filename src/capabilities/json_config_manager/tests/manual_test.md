# Teste manual — [CDXMS] Json Config Manager v1.0.0

1. Importe o export `macrodroid/[CDXMS]_Json_Config_Manager.ablock`.
2. Execute uma operação válida com entradas mínimas.
3. Confirme `Resultado.success = true` e `Resultado.artifact_id = "json_config_manager"`.
4. Execute uma operação inválida.
5. Confirme erro estruturado e ausência de falha silenciosa.
