# Teste manual — [CDXMS] Logger v1.0.0

1. Importe o export `macrodroid/[CDXMS]_Logger.ablock`.
2. Execute uma operação válida com entradas mínimas.
3. Confirme `Resultado.success = true` e `Resultado.artifact_id = "logger"`.
4. Execute uma operação inválida.
5. Confirme erro estruturado e ausência de falha silenciosa.
