# Homologação do JUIF Event Bridge

Importe e habilite o Receiver, importe o Sender e execute o Sender manualmente. O Receiver deve disparar uma única vez, preencher os extras e publicar Resultado.success como verdadeiro.

Os extras do trigger são filtros de correspondência. Campos estáveis usam valores exatos e campos dinâmicos usam curinga. Valor vazio não significa aceitar qualquer conteúdo.
